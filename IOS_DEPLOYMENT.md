## Step-by-Step Deployment

### Phase 1: Apple Developer Setup

1. **Enroll in Apple Developer Program** ($99/year)
   - https://developer.apple.com/programs/
   - You do NOT need a Mac to enroll

2. **Register your App ID**
   - Go to Certificates, Identifiers & Profiles
   - Register identifier: `com.picklepro.app`
   - Enable capabilities: Push Notifications, Sign in with Apple

3. **Create your app in App Store Connect**
   - https://appstoreconnect.apple.com
   - New App → iOS → Bundle ID: `com.picklepro.app`
   - Fill in app name: "PicklePro"

### Phase 2: Generate the iOS Project

Run these commands (works on any platform):

```bash
# Build the web assets
npm run build

# Generate the iOS Xcode project
npx cap add ios

# Sync web assets into the iOS project
npx cap sync ios
```

This creates the `ios/` folder with a full Xcode project.

### Phase 3: App Icon & Splash Screen

Replace the default Capacitor icons in `ios/App/App/Assets.xcassets/`:

**Required App Icon Sizes:**
- 1024x1024 (App Store)
- 180x180 (@3x iPhone)
- 120x120 (@2x iPhone)
- 167x167 (iPad Pro)
- 152x152 (iPad)
- 80x80 (Spotlight @2x)
- 120x120 (Spotlight @3x)
- 40x40 (Settings @2x)
- 60x60 (Settings @3x)

**Recommended:** Use a tool like https://appicon.co to generate all sizes from a single 1024x1024 PNG.

**Splash Screen:** Edit `ios/App/App/Assets.xcassets/Splash.imageset/` with your splash image, or use a simple dark background (#0a0a0a) with the PicklePro logo centered.

### Phase 4: Cloud Build Setup

#### Option A: Codemagic (Recommended for beginners)

1. Sign up at https://codemagic.io (500 free build minutes/month)
2. Connect your GitHub repo
3. Codemagic auto-detects the `codemagic.yaml` config
4. In dashboard → Code signing:
   - Use "Automatic" signing (Codemagic manages certs for you)
   - Enter your Apple Developer credentials
5. In dashboard → Distribution:
   - Add App Store Connect API key for auto-upload
6. Push a tag (`git tag v1.0.0 && git push --tags`) to trigger

#### Option B: GitHub Actions

1. Generate code signing certificates manually:
   - Distribution Certificate (.p12)
   - Provisioning Profile (.mobileprovision)
   - App Store Connect API Key (.p8)
2. Add as GitHub secrets (see `.github/workflows/ios-build.yml` header)
3. Push a version tag to trigger

### Phase 5: TestFlight

After a successful cloud build:
1. The IPA is uploaded to App Store Connect automatically
2. Go to App Store Connect → TestFlight
3. Wait for Apple's processing (5-30 minutes)
4. Add internal testers (email-based)
5. Test on real iOS devices

### Phase 6: App Store Submission

See the checklist below.

## App Store Submission Checklist

### Required Before Submission

- [ ] **App Icon** — 1024x1024 PNG, no transparency, no rounded corners (Apple adds them)
- [ ] **Screenshots** — Required for 6.7" and 5.5" display sizes minimum
  - 6.7" (iPhone 15 Pro Max): 1290 x 2796
  - 5.5" (iPhone 8 Plus): 1242 x 2208
  - Upload 3-5 screenshots per size
- [ ] **App Description** — 4000 character max, concise and keyword-rich
- [ ] **Privacy Policy URL** — Required. Host a simple page explaining data handling
- [ ] **Support URL** — Required. Can be a simple contact page or email
- [ ] **Age Rating** — Fill out the questionnaire (PicklePro is likely 4+)
- [ ] **App Category** — Sports or Health & Fitness

### Required by Apple Guidelines

- [ ] **Sign in with Apple** — Required if you offer ANY social sign-in option
  - Already prepared in `AuthService.js`
- [ ] **Restore Purchases** button — Required if you have IAP
  - Already prepared in `SubscriptionService.js`
- [ ] **No web-only purchase links** — Don't link to external payment pages
- [ ] **Content must work offline** — The app should be useful without internet
  - PicklePro works fully offline (localStorage)
- [ ] **No placeholder content** — All screens must have real content or graceful empty states
  - Already implemented across all screens

### Technical Requirements

- [ ] **Minimum iOS version** — Set to iOS 16+ (covers ~95% of devices)
- [ ] **Dark mode support** — PicklePro is dark-only, which is fine
- [ ] **Safe area support** — Implemented via CSS `env(safe-area-inset-*)`
- [ ] **Keyboard handling** — Implemented via Capacitor Keyboard plugin
- [ ] **No crashes** — Test all flows in TestFlight before submitting
- [ ] **Performance** — Web view should feel responsive (PicklePro is <380KB bundled)

### Optional but Recommended

- [ ] **App Preview Video** — 15-30 second video showing the app in action
- [ ] **Subtitle** — 30 characters max, appears under app name
  - Suggestion: "Your Pickleball Growth Coach"
- [ ] **Keywords** — 100 characters max, comma-separated
  - Suggestion: "pickleball,training,journal,coach,mental game,drills,skills,progress,improvement"
- [ ] **What's New** text for updates

## Environment Variables

Create a `.env` file for production configuration:

```bash
# AI Coach (when activating real AI)
VITE_AI_PROVIDER=mock          # Change to 'anthropic' when ready
VITE_AI_PROXY_URL=/api/coach   # Your backend proxy URL

# Supabase (when activating backend)
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key

# RevenueCat (when activating subscriptions)
VITE_REVENUECAT_API_KEY=your-revenuecat-key
```

## Common Issues

**"WKWebView is blank on device"**
→ Run `npx cap sync ios` after every `npm run build`

**"Safe area not working"**
→ Ensure `viewport-fit=cover` is in your meta viewport tag (already set)

**"localStorage not persisting"**
→ Capacitor WKWebView localStorage persists by default. If issues occur, switch StorageService to `@capacitor/preferences` (async API)

**"App rejected for missing privacy manifest"**
→ iOS 17+ requires a PrivacyInfo.xcprivacy file. Capacitor 6+ generates one. If missing, create `ios/App/App/PrivacyInfo.xcprivacy` with NSPrivacyTracking = false.
